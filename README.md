# Gangsar Futsal Booking Deployment

## Overview
This repository documents the deployment process of a Laravel-based futsal booking web application using Ubuntu Server as the web server.

The project focuses on server service implementation, Laravel deployment, Apache configuration, MySQL database setup, and server administration. During the project, the application was deployed on a Virtual Private Server (VPS) and made publicly accessible through a custom domain as part of the final project demonstration.

## Objectives
- Prepare and configure Ubuntu server as a web server
- Deploy Laravel application to a VPS 
- Configure Apache Virtual Host
- Configure MySQL Database
- Configure SSH for remote server administration
- Configure UFW Firewall to secure server access
- Connect the web application to a public domain
- Test and verify public access to application
